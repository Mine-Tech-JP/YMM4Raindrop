# 雫と拭痕（しずくとふきあと） – RainDrop & GlassWipe for YMM4 ユーザーズマニュアル

by Mine-Tech / 対象バージョン 1.0.0 / 内容基準日 2026年9月26日

[ブラウザ版を開く](USER_GUIDE.html)

<a id="overview"></a>

## できること

雫と拭痕（しずくとふきあと）は、映像に曇りやホコリを思わせる層を重ね、ブラシが通った場所を拭き取るYMM4用の映像エフェクトです。
ガラスの外側に水滴や雨だれを加え、曇った窓を内側から拭くような演出も作れます。

| 作りたい演出 | 主に使う設定 |
| --- | --- |
| 曇ったガラスを拭く | 曇り量、ぼかし量、拭き方、ブラシ |
| 映像に水滴や雨だれを重ねる | 外側の水滴量、水滴を垂らす、雨の降り始め |
| 水滴のついた窓を内側から拭く | 曇りと水滴を両方有効にする |

**外側の水滴は、ブラシで拭いても消えません。**
曇った部分では背景と水滴が一緒にぼけ、拭いた部分では水滴が鮮明に見えます。

<a id="install"></a>

## 導入とエフェクトの追加

### 動作環境

- ゆっくりMovieMaker4 v4.56.1.0以降
- 64-bit版のWindows 10 Version 2004（build 19041）以降、またはWindows 11
- DirectX 11対応GPU

本プラグインはMine-Techが開発した非公式の第三者製プラグインです。

### インストール

手順2と3は、配布形式に応じてどちらか一方だけを行います。

1. YMM4を終了します。
2. 配布された`.ymme`がある場合はダブルクリックし、YMM4の案内に従ってインストールします。
3. DLLで導入する場合は、`YMM4GlassWipe.dll`をYMM4の`user\plugin\YMM4GlassWipe`へ配置します。
4. YMM4を起動します。

同じDLLを複数のプラグインフォルダーへ残さないようにしてください。

### アイテムへ追加する

1. タイムラインで映像アイテム、画像アイテム、またはエフェクトアイテムを選びます。
2. 「映像エフェクト」を追加し、「描画」から「雫と拭痕」を選びます。

YMM4側で本エフェクトのデフォルトを変更していない場合、新しく追加したエフェクトは、「設定方法」が「標準設定」になっています。
追加直後の見た目と動きは、次の「新しく追加したときの設定」で説明します。

エフェクトアイテムで使う場合は、YMM4側の「領域」も確認します。
その領域が小さいと、プラグインで「入力領域全体」を選んでも、その小さい範囲だけに効果がかかります。

## 新しく追加したときの設定

YMM4側で本エフェクトのデフォルトを変更していない場合、新しく追加すると、「標準設定」で曇り、水滴、手形による拭き取りが有効になっています。
各項目の初期値と役割は、次の表で確認できます。
水滴の動きは「簡易物理」、見た目は「リアル（屈折）」です。

### 主な初期値

保存したプロジェクトやテンプレートを読み込む場合は、その保存値が優先されます。
初期値の更新によって、配置済みのエフェクトの値が自動で変わることはありません。

| 項目 | 初期値 | 項目の解説 |
| --- | --- | --- |
| 設定方法 | 標準設定 | よく使う設定をまとめた標準設定と、個別に調整できる詳細設定を切り替えます。 |
| 拭き方 / 点のつなぎ方 | 往復拭き（ずれ） / 円弧（3点） | 拭き取りの動きと、始点、経由点、終点を結ぶ軌跡の形を選びます。 |
| 始点 / 経由点 / 終点 | （X 15%, Y 50%） / （X 50%, Y 30%） / （X 75%, Y 30%） | 拭き取り軌跡の開始位置、曲線を通る位置、終了位置を指定します。 |
| 往復回数 / 拭き取り量 | 3.5回 / 100% | 軌跡を往復する回数と、片道ごとに取り除く曇りの割合を調整します。 |
| ずれX / ずれY | 3% / 10% | 往復するたびに軌跡を横方向、縦方向へ移動させます。 |
| 時間指定方式 | 秒数 | 軌跡を描き始める時刻と描き終える時刻の指定方法を選びます。 |
| 描画開始秒 / 描画完了秒 | 0.5秒 / 3秒 | アイテムの先頭を0秒として、拭き取りを始める時刻と完成状態になる時刻を指定します。 |
| 領域 / 境界ぼかし | 入力領域全体 / 10px | 曇りを適用する範囲と、その境界を周囲へなじませる幅を調整します。 |
| 曇り量 / ぼかし量 / 色の混合量 | 90% / 10px / 10% | 曇りの強さ、曇った部分のぼかし、指定色を混ぜる割合を調整します。 |
| 曇りノイズ | 10% | 曇り色に濃淡を加えます。0%で無効になります。 |
| ブラシ / 連続拭き | 手形 / ON | 拭き取りに使う形状を選び、手形・靴跡・ユーザー画像の跡を移動に沿ってつなぎます。 |
| 円の直径 / 楕円の幅・高さ / 四角形の幅・高さ | 500px / 25×50px / 100×620px | 生成形状の大きさを入力素材上のピクセル数で指定します。 |
| サイズ倍率 | 50% | 手形、靴跡、ユーザー画像を、PNG元キャンバスの幅・高さを基準に等率で拡大縮小します。 |
| 左右反転 / 回転角 | ON / -30° | 手形を反転し、ブラシの向きを調整します。 |
| 回転追従 | 100% | 移動方向へブラシの向きを合わせる割合を調整します。 |
| 外側の水滴量 / 水滴の濃さ | 50% / 100% | 拭き取り後も残る外側の水滴の個数と、輪郭、ハイライト、影の見え方を調整します。 |
| 水滴サイズ | 100% | 水滴の大きさを調整します。 |
| 水滴の動き / 水滴の見た目 | 簡易物理 / リアル（屈折） | 大きさに応じて滑る水滴に、背景の縮小像と歪みを描きます。 |
| 輪郭の濃さ | 30% | 水滴と水筋の暗い縁を調整します。 |
| 滑りやすさ / 雨の補給 | 100% / 200% | 滴の滑り始めやすさと、追加の雨の補給量を調整します。簡易物理で使います。 |
| 垂れる速さ / 水筋の長さ | 100% / 100% | 滴の動く速さと、後ろに残す水筋の長さを調整します。 |
| 水滴を垂らす / 水滴の合体 / 雨の降り始め | すべてON | 水滴の落下、接触した水滴の吸収、水滴ごとの出現時刻の分散を切り替えます。 |
| 出現開始時間 / 出現期間 | 1秒 / 10秒 | 水滴が現れ始める時刻と、水滴ごとの初回出現時刻を分散する期間を指定します。 |

> **「連続拭き」の意味**
>
> 手形・靴跡・ユーザー画像の跡を移動に沿ってつなげる機能です。
> 拭く動作を繰り返す機能ではありません。
> 一回で拭くか往復するかは「拭き方」、往復する回数は「往復回数」で指定します。

> **YMM4の「デフォルトに設定」を使った場合**
>
> 現在の設定が、次に新しく追加する同じエフェクトの初期設定として使われます。
> 上の表は、YMM4側で本エフェクトのデフォルトを変更していない場合の値です。
> すでに配置済みのエフェクトや、保存済みプロジェクトの設定は変更されません。

<a id="try-defaults"></a>

## そのまま動かしてみる

初期設定は、曇り、拭き取り、水滴、雨だれを一度に確認できる「全部入り」の状態です。
まずは設定を変えずに動かし、それぞれの機能がどのように重なるかを確認します。

### 準備

1. 15秒程度の映像または画像アイテムを用意します。
2. 「雫と拭痕」を追加します。
3. 設定を変更せず、アイテムの先頭から12秒以上プレビューします。

### 見るポイント

| 15秒のアイテムでの再生位置 | 確認できる動き |
| --- | --- |
| 0秒から0.5秒 | 入力領域全体に曇りがかかり、拭き取りはまだ始まりません。 |
| 0.5秒から3秒 | 手形の拭き跡が円弧に沿って3.5回往復し、往復する位置を右下方向へずらします。最後は終点側で止まり、手形の跡は「連続拭き」によってつながります。 |
| 1秒から11秒 | 最初の水滴が順に現れます。簡易物理では大きさに応じて滴が滑り、接触した滴が合体します。落下や合体の時刻は滴ごとに異なります。 |
| 3秒以降 | 完成した拭き跡を維持します。外側の水滴は拭き取られず、曇りが消えた場所では鮮明に見えます。 |

「出現期間」の10秒は最初の水滴が現れる期間です。「雨の補給」が200%なので、その後も追加の雨を補給します。画面内の滴が上限に達した場合は補給を見送ります。

この動作から、拭き取りと水滴は別々に進むこと、「連続拭き」は手形の跡をつなぐ機能であることを確認できます。
初期動作を確認したら、次の「まず作ってみる」で目的に合わせて設定を変えます。

<a id="quick-start"></a>

## まず作ってみる

次の設定例は、動きと見た目を確認するための出発点です。
素材に合わせて位置や大きさを調整しながらプレビューしてください。

### 中央を左から右へ拭く

10秒程度の映像または画像アイテムにエフェクトを追加し、次の順に設定します。

1. 「領域」の形状を「入力領域全体」にします。
2. 「外側の水滴量」を0%にします。
3. 「曇り量」を90%、「ぼかし量」を10pxにします。
4. 「拭き方」を「一回拭き（直線）」にし、始点をX 25% / Y 50%、終点をX 75% / Y 50%にします。
5. 「ブラシ」の形状を「円」、直径を140pxにします。
6. 「時間指定方式」を「秒数」にし、描画開始秒を1秒、描画完了秒を3秒にします。
7. 先頭からプレビューします。1秒から3秒の間に中央を拭き、その後は拭き跡を維持します。

手で拭く形に変える場合は、形状を「手形」にします。
手形、靴跡、ユーザー画像は「サイズ倍率」で大きさを調整します。
PNG元キャンバスの幅・高さと透明な余白を基準に、25%から400%まで等率で拡大縮小します。
既定値は50%です。
形状を手形にすると、初期設定と同じく「連続拭き」がONになり、手形の跡が移動に沿ってつながります。
この設定例の「一回拭き（直線）」は、一度だけ拭く動きのままです。

### 水滴や雨だれだけを重ねる

1. 「曇り量」を0%にします。
2. 「外側の水滴量」を70%、「水滴の濃さ」を70%にします。
3. 「水滴の見た目」を「黒い輪郭」、「輪郭の濃さ」を40%にします。
4. 「水滴を垂らす」をONにします。
5. 「雨の降り始め」をOFFにしてプレビューすると、先頭から水滴を表示できます。

途中から水滴が現れる演出にする場合は、「雨の降り始め」をONにします。
たとえば出現開始時間を1秒、出現期間を3秒にすると、1秒後から4秒後にかけて滴が順に現れます。
静止した水滴だけを見せる場合は、「水滴を垂らす」をOFFにします。
簡易物理では、OFFにしても雨の補給と接触合体は続きます。追加の雨も止める場合は「雨の補給」を0%、合体も止める場合は「水滴の合体」をOFFにします。

### 水滴のついた窓を内側から拭く

上の水滴と雨だれの設定に「曇り量」と「ぼかし量」を加え、標準設定の拭き方を選びます。
水滴を先に見せたい場合は、水滴の出現開始時間を拭き取りの描画開始より早くします。

拭いた場所では曇りが減り、窓の外側に残った水滴がはっきり見えるようになります。
水滴の出現時間と拭き取りの描画時間は、それぞれ別に設定します。

<a id="patterns"></a>

## 拭き方と点のつなぎ方

### 5種類の拭き方

| 拭き方 | 動き | 主に調整する項目 |
| --- | --- | --- |
| 一回拭き（直線） | 始点から終点へ一度だけ拭く | 始点、終点 |
| 一回拭き（経由点あり） | 経由点を通って一度だけ拭く | 始点、経由点、終点、点のつなぎ方 |
| 往復拭き（直線） | 直線を往復する | 始点、終点、往復回数、拭き取り量 |
| 往復拭き（経由点あり） | 曲がった軌跡を往復する | 始点、経由点、終点、点のつなぎ方、往復回数、拭き取り量 |
| 往復拭き（ずれ） | 往復ごとに位置をずらす | 始点、終点、点のつなぎ方、往復回数、拭き取り量、ずれX、ずれY。曲線または円弧では経由点も使用 |

始点などの位置は、効果をかける領域の中での百分率です。
Xは右へ、Yは下へ行くほど値が大きくなります。

選んだ拭き方で使う項目だけが表示されます。
非表示になった値は保持されるため、元の拭き方へ戻すと再利用できます。

<a id="interpolation"></a>

### 直線、曲線、円弧

「点のつなぎ方」は、経由点ありの2種類と「往復拭き（ずれ）」で選べます。

| 選択肢 | 形の決まり方 |
| --- | --- |
| 直線 | 点を直線でつなぎます。折れ曲がりを残したいときに使います。 |
| 曲線（Catmull-Rom） | 制御点を滑らかにつなぎます。 |
| 円弧（3点） | 始点、経由点、終点を通る円弧を作ります。経由点は円の中心ではなく、円弧が通る点です。 |

「一回拭き（直線）」と「往復拭き（直線）」は、常に直線で結びます。
「往復拭き（ずれ）」で直線を選んだ場合、経由点は使いません。

円弧にしたい場合は、経由点を始点と終点の直線から離します。
3点が一直線に並ぶか、同じ位置に重なる場合は、曲線方式へ切り替えて処理します。

<a id="progressive"></a>

### 往復で少しずつ拭く

往復回数は1.0回から5.0回まで、0.5回単位で指定できます。
整数の回数では始点側へ戻って終わります。
1.5回なら「始点→終点→始点→終点」と進み、終点側で拭き終わります。
「往復拭き（ずれ）」では、最後の半往復も、それまでに完了した往復分だけずれた終点へ進みます。
「拭き取り量」は、往復する3種類の拭き方で使います。

拭き取り量は片道ごとに、残っている曇りの何%を取り除くかを指定します。
100%なら最初の通過で拭き取り、0%なら拭き取りません。

たとえば40%にすると、同じ場所を通った回数に応じて、曇りを取り除く割合は1回で40%、2回で64%、3回で約78%になります。
初期値は100%なので、少しずつ見せたいときは20%から50%程度へ下げて調整します。

「往復拭き（ずれ）」では、ずれXとずれYをそれぞれ-20%から20%の範囲で指定できます。
Xの正の値は右、Yの正の値は下へずらします。
軌跡が領域の端を越えた部分は表示されません。

<a id="timing"></a>

## 拭き取りの開始時間と進み方

### 描き始めと描き終わり

「時間指定方式」で、使いたい単位を選びます。
選択した方式の開始値と完了値だけが描画に使われます。

| 時間指定方式 | 画面の項目 | 指定する位置 |
| --- | --- | --- |
| パーセンテージ | 描画開始位置 / 描画完了位置 | アイテム全体に対する割合 |
| 固定フレーム | 描画開始フレーム / 描画完了フレーム | アイテムの先頭を0とするフレーム数 |
| 秒数 | 描画開始秒 / 描画完了秒 | アイテムの先頭からの秒数 |

パーセンテージは、アイテムの長さを変えると描画にかかる時間も変わります。
秒数で開始1秒、完了3秒とすれば、描画する区間は2秒です。
完成状態を長く見せるには、描画完了より後までアイテムを延ばします。

固定フレームまたは秒数の完了値がアイテム終端より後にあると、途中まで拭いた状態で終わります。
完了値を開始値以下にすると、開始位置で完成状態へ切り替わります。

### 進行度で加減速する

標準設定の「進行度」は、軌跡全体のどこまで拭くかを指定します。
初期値は0%から100%への直線移動です。
YMM4のAnimation設定で加減速を変更すると、軌跡の形を保ちながら進み方を変えられます。

往復する場合は、設定した全往復を進行度0%から100%へ割り当てます。
進行度50%が何回目の折り返しになるかは、往復回数によって変わります。

### 中間点を使う場合

YMM4で拭き取り用のAnimationに中間点を追加すると、アイテム全体に対する中間点の位置を、描画開始から完了までの区間へ対応させます。
たとえばアイテム中央の中間点は、描画開始0.5秒、完了3秒なら、拭き取りの1.75秒の位置に対応します。
進行度、キーフレーム軌跡の座標や接触率、拭き取り強度、ブラシの寸法や回転が対象です。
曇り量など映像全体のAnimationは、アイテム上の時刻どおりに変化します。

<a id="brush"></a>

## ブラシの形と大きさ

「ブラシ」の「形状」は、標準設定でも詳細設定でも選べます。

| 形状 | 用途と調整 |
| --- | --- |
| 円 | 丸い拭き跡。直径をピクセル単位で指定します。 |
| 楕円 | 楕円の拭き跡。幅と高さを別々にピクセル単位で指定します。 |
| 四角形 | 四角い面で拭く形。幅と高さを別々にピクセル単位で指定します。 |
| 手形 | 指のある形。「サイズ倍率」「左右反転」と「連続拭き」を使えます。 |
| 靴跡 | 靴底の形。「サイズ倍率」「左右反転」と「連続拭き」を使えます。 |
| ユーザー画像 | 登録したPNGの透過情報をブラシに使います。「サイズ倍率」「左右反転」「連続拭き」を使えます。 |

### 大きさ、幅、向き

| 項目 | 調整する内容 |
| --- | --- |
| 直径 | 円で使用。入力素材上の直径を0pxから8192pxで指定します。 |
| 幅・高さ | 楕円と四角形で使用。入力素材上の寸法をそれぞれ0pxから8192pxで指定します。 |
| サイズ倍率 | 手形、靴跡、ユーザー画像で使用。PNG元キャンバスの幅・高さへ同じ倍率を掛けます。25%から400%で指定し、100%は元キャンバスと同じ大きさです。 |
| 回転角 | ブラシの向きを調整します。手形の指先と靴跡の爪先は0°で上向きです。 |
| 回転追従 | 移動方向に合わせてブラシが向きを変える割合です。回転角は追従した向きにも加算されます。 |
| 左右反転 | 手形、靴跡、ユーザー画像を左右に反転します。 |

寸法値は標準設定と詳細設定で共通です。

### ピクセル寸法の入力例

| 作りたい形 | 形状と設定値 |
| --- | --- |
| 直径10pxの円 | 「円」を選び、直径を10pxにします。 |
| 直径140pxの円 | 「円」を選び、直径を140pxにします。 |
| 幅25px、高さ50pxの楕円 | 「楕円」を選び、幅を25px、高さを50pxにします。 |
| 幅100px、高さ30pxの四角形 | 「四角形」を選び、幅を100px、高さを30pxにします。 |

直径、幅、高さはYMM4のAnimationに対応します。
入力欄は整数表示ですが、キーフレーム間では小数値も補間されます。
円は直径0px、楕円と四角形はいずれかの寸法が0pxになると描画しません。

ここでいうピクセルは、エフェクトへ入力される画像上の寸法です。
YMM4側でアイテムを拡大縮小、回転、四隅指定すると、ブラシも入力画像と一緒に変形されるため、プレビュー上の見かけの寸法は変わります。

手形、靴跡、ユーザー画像はPNG全体の元キャンバス寸法を使います。
透明な余白も基準寸法に含み、「サイズ倍率」を幅・高さへ等率で適用します。
円、楕円、四角形では「サイズ倍率」は表示せず、ピクセル寸法を指定します。

手形と靴跡は、往復の折り返しで上下が反転しないように向きを維持します。
四角形も折り返し前の向きを保ち、復路では往路と同じ向きを基準に回転追従を適用します。
回転追従を100%未満にした場合も、この基準で向きを調整します。

<a id="continuous-wipe"></a>

## 手形・靴跡・ユーザー画像をつなげて拭く

新しく追加したエフェクトでは、手形・靴跡・ユーザー画像の**連続拭き**が最初からONです。
移動に沿ってブラシ形状がつながります。
回転やサイズの変化も補間するため、スタンプを並べたときの隙間を減らせます。
始点と終点にはブラシの形が残ります。

> **拭く回数や往復動作は変わりません。**
>
> 「連続拭き」は、拭く回数や往復動作を変えません。
> 「一回拭き」では、一度だけ拭きます。
> 繰り返し拭く場合は、「拭き方」で往復するパターンを選び、「往復回数」を設定します。

1. 「ブラシ」の形状を手形、靴跡またはユーザー画像へ切り替えます。
2. 「連続拭き」がONの状態で軌跡をプレビューします。
3. 回転追従を調整します。

スタンプ状の跡を残したい場合は、連続拭きをOFFにします。
手形・靴跡・ユーザー画像へ切り替えた場合もONになりますが、同じ形状を再指定しただけなら、手動でOFFにした値を保持します。
プロジェクトの読み込み、複製、プリセット適用、Undo／Redoでは保存されているON／OFFを維持します。

詳細設定で接触率を0%にした区間や、別々のストロークの間はつながりません。
連続拭きは手形・靴跡・ユーザー画像の設定です。

<a id="region"></a>

## 効果をかける範囲

| 領域の形状 | 設定する内容 |
| --- | --- |
| 入力領域全体 | エフェクトへ渡された映像全体にかけます。 |
| 四角形 | 中心X、中心Y、幅、高さ、回転角を調整します。 |
| 円または楕円 | 中心X、中心Y、幅、高さ、回転角を調整します。 |
| 四角形（四隅指定） | 台形の窓などに合わせ、左上、右上、右下、左下を指定します。 |

「境界ぼかし」を増やすと、領域の縁がなだらかになります。
領域内の拭き跡は、現在の領域の位置や形に合わせて表示されます。

四隅を直接調整する場合は、領域の形状を「四角形（四隅指定）」にし、四隅指定側のプリセットを「カスタム」にします。
各頂点は入力画像に対する座標で、-100%から200%まで指定できます。
負の値や100%を超える値を使えば、画面外まで続く窓にも合わせられます。
四辺が交差するなど不正な形になると、効果が消えて入力映像をそのまま表示します。

四隅指定で水滴も面の遠近に合わせたい場合は、水滴の動きを「周期動作」、見た目を「白い輪郭」か「黒い輪郭」にして、「面に合わせる」をONにします。
「リアル（屈折）」は水滴の形を画面上で保ち、四隅の領域で切り抜きます。面の遠近に沿った水滴の変形には対応しません。
OFFにすると、水滴の丸みと画面下方向への落下を優先して、領域内に表示します。

<a id="appearance"></a>

## 曇りの見た目

| 項目 | 調整する内容 |
| --- | --- |
| 曇り量 | 曇りの強さ。0%で曇りを表示しません。 |
| ぼかし量 | 曇っている部分の映像をぼかす量。 |
| 曇り色 | 曇りに混ぜる色。 |
| 色の混合量 | 曇り色を混ぜる強さ。 |
| 曇りノイズ | 曇り色に濃淡を加えます。初期値は10%、0%で無効になります。 |

この章の項目は標準設定と詳細設定の両方で使えます。
曇り量を固定0%にすると、ぼかし量、曇り色、色の混合量、曇りノイズは非表示になります。
Animationの有効な設定値に0%より大きい値が含まれる場合は、現在フレームの曇り量が0%でも表示されます。

曇りノイズの模様は「ブラシ」の「Seed」で固定されます。
Seed自体は詳細設定のキーフレームまたはカスタム軌跡で表示されます。

曇り量を0%にしても、有効にした水滴は残ります。
曇りの強い部分では水滴も見えにくくなるため、水滴を調整するときはいったん曇り量を下げると変化を確認しやすくなります。

<a id="outside-droplets"></a>

## 水滴と雨だれの設定

「外側の水滴量」を0%より大きくすると、水滴を表示できます。
0%では、ほかの水滴設定が非表示になります。

### 水滴の動きを選ぶ

新しく追加したエフェクトの既定は「簡易物理」です。動きの選択項目がない古い保存データは「周期動作」として読み込み、保存済みの選択は維持します。
周期動作は設定した待ち時間や周期に沿って水滴が落下します。簡易物理は水滴の大きさや滑りやすさに応じて動き、接触すると合体します。どちらも「水滴を垂らす」と「水滴の合体」のON/OFFに従います。
大きくなった滴が滑り始める演出には「簡易物理」を選びます。切り替えても、ほかの設定値は変わりません。

| 項目 | 初期値 | 使い方 |
| --- | --- | --- |
| 水滴の動き | 簡易物理 | 周期動作／簡易物理を切り替えます。見た目の選択とは独立しています。 |
| 滑りやすさ | 100% | 簡易物理だけで表示。25〜400%。高くすると小さい滴も滑り始めやすくなります。 |
| 雨の補給 | 200% | 簡易物理だけで表示。0〜400%。0%で追加の雨を止めます。 |

簡易物理では、小さい滴はその場に留まり、大きい滴は画面下へ滑ります。
「水滴の合体」がONなら接触した滴の水量を足し合わせるため、合体をきっかけに滑り始めることもあります。
「水滴を垂らす」をOFFにしても、補給と接触合体は続きます。

「外側の水滴量」は初期候補数に対応し、50%で128滴、100%で256滴です。合体などで実際に見える数は減ります。
同時に存在する物理粒子は最大256滴で、上限では補給を見送ります。合体途中の表示は別に補間します。
「垂れる速さ」は運動の時間倍率で、雨の出現時刻と補給間隔は変えません。
「水筋の長さ」は簡易物理でも使えますが、長さには画面高さに応じた上限があります。

簡易物理では「垂れる割合」「垂れる頻度」「面に合わせる」は表示しません。周期動作へ戻すと保存値を再利用します。
四角形（四隅指定）を含む領域の内側へ切り抜けますが、水滴の形や重力は面の傾きに追従しません。三次元の流体計算ではありません。

### 水滴の見た目

| 項目 | 新規追加時の値 | 使い方 |
| --- | --- | --- |
| 外側の水滴量 | 50% | 水滴の量を調整します。0%で非表示です。 |
| 水滴サイズ | 100% | 水滴の大きさを変えます。 |
| 水滴の濃さ | 100% | 水滴全体の輪郭や反射などの強さを変えます。 |
| Seed | 0 | 配置や動きのパターンを変えます。 |
| 水滴の見た目 | リアル（屈折） | 「白い輪郭」「黒い輪郭」「リアル（屈折）」を切り替えます。 |
| 輪郭の濃さ | 30% | 黒い輪郭またはリアルで表示します。黒い縁と水筋の暗い縁を調整します。 |
| 面に合わせる | ON | 周期動作の白い輪郭／黒い輪郭で、四隅指定の面変形へ水滴を合わせます。リアルと簡易物理では非表示となり、保存値を維持します。 |

黒い輪郭は、透ける中心と暗い縁、上側の白い反射を持つ見た目です。
輪郭の濃さを0%にすると黒い縁が消え、白い反射は残ります。
反射も含めて薄くしたい場合は、水滴の濃さを下げます。

リアル（屈折）は、水滴内に入力映像を上下左右反転して縮小し、歪めた像を描きます。
水筋には輪郭と反射を描きます。背景の奥行きまで再現する物理シミュレーションではありません。
新規追加時はリアルが選ばれています。屈折を確認するときは、水滴サイズを上げ、文字や模様のある背景でプレビューします。別の見た目を使っている場合は「リアル（屈折）」に切り替えます。
四隅指定では水滴の面変形を行いません。周期動作の「白い輪郭」か「黒い輪郭」へ戻すと「面に合わせる」の保存値を再利用します。
屈折像を含めて薄くするには「水滴の濃さ」を調整します。

### 周期動作の垂れる水滴と水筋

「水滴を垂らす」をONにすると、次の項目が表示されます。
OFFにすると水滴は静止します。

| 項目 | 新規追加時の値 | 使い方 |
| --- | --- | --- |
| 垂れる割合 | 100% | 落下する水滴の比率。0%では落下しません。 |
| 垂れる速さ | 100% | 落下速度。合体などによる変化を除く基準では、100%で領域の高さを約6秒で移動します。 |
| 垂れる頻度 | 200% | 100〜400%で落下滴の候補数を増やします。400%では候補数が最大4倍になります。 |
| 水筋の長さ | 100% | 落下した滴の後ろへ残す筋の長さ。0%では筋を表示しません。 |
| 水滴の合体 | ON | 接触する小さい滴を大きい滴へ吸収します。 |

滴を大きくしたり速くしたりせず、同じ時間内で垂れる数を増やしたい場合は「垂れる頻度」を上げます。
発生はランダムで、毎秒一定の回数を指定する機能ではありません。
水滴量、垂れる割合、合体によって実際に見える数は変わります。
高い頻度では合体判定と描画の負荷が増えます。

落下中の滴は上側が細い形へ変化し、水筋は滴の上端へつながります。
合体すると落下滴が大きくなり、落下速度も変化します。
初めから重なる静止滴や、落下滴同士も吸収の対象です。

合体では一定の区間を繰り返して描画します。
途中で吸収された静止滴は、区間の終わりに初期配置へ戻ることがあります。

### 雨の降り始め

「雨の降り始め」をONにすると、滴ごとの出現時刻をずらせます。
滴ごとの初回出現時刻を、指定した期間内へ分散します。
出現した滴は落下や合体で消えることもあるため、画面に見える数が増え続けるとは限りません。

| 項目 | 新規追加時の値 | 使い方 |
| --- | --- | --- |
| 雨の降り始め | ON | OFFでは先頭から水滴を表示します。 |
| 出現開始時間 | 1秒 | アイテムの先頭から、水滴が現れ始めるまでの時間。 |
| 出現期間 | 10秒 | 出現開始時間から、滴を出現させる時間幅。0秒なら一斉に出現します。 |

出現開始時間と出現期間は、雨の降り始めがONのときだけ表示します。
小数の秒数で指定でき、範囲は0秒から36,000秒です。

簡易物理では、これは初期滴が現れる時間の設定です。「出現期間」の終了後も「雨の補給」は続きます。
補給を止めるには「雨の補給」を0%にします。「雨の降り始め」がONなら、補給も出現開始時間以降に始まります。

まだ出現していない滴は、落下や合体を始めません。
「水滴を垂らす」がOFFでも、静止した水滴が順に現れる演出を作れます。
水滴の出現時間は、拭き取りの描画時間や垂れる速さと独立しています。

同じバージョン、設定、Seed、再生位置では、同じ水滴の状態を再現する設計です。

<a id="detailed"></a>

## 詳細設定で軌跡を作る

「設定方法」を「詳細設定」にすると、「軌跡の種類」を選べます。
新規エフェクトを標準設定から切り替えた直後は「定型軌跡」で、標準設定と同じ軌跡設定を表示します。

| 軌跡の種類 | 作り方 |
| --- | --- |
| 定型軌跡 | 標準設定で決めた拭き方と軌跡設定を使います。 |
| キーフレーム | 「軌跡」グループのX、Y、接触率などをYMM4のAnimationで動かします。 |
| カスタム軌跡 | 複数のストロークと制御点を編集します。 |

**ストローク**は、ブラシを離さずに描く一続きの軌跡です。
別々のストロークの間には線を引きません。
キーフレームでは、接触率を0%にした区間をブラシを持ち上げた状態として扱います。

カスタム軌跡のXとYは、1920×1080の基準キャンバス上の整数ピクセルで指定します。
時刻と接触率はパーセント指定のままです。
実際の領域には縦横比を保って収め、余る方向を中央へ寄せるため、ハート、相合い傘、スマイルなどの図柄が領域の縦横比で歪みません。
基準キャンバスの左上はX 0px、Y 0px、右下はX 1920px、Y 1080pxです。
領域が16:9でない場合は、余る方向の両側に同じ幅の余白を置くため、軌跡が領域の端まで届かない場合があります。
同じ相対範囲を指定した3840×2160の入力では、1920×1080の入力に対して軌跡も2倍の大きさになります。

### 拭き跡を細かく調整する

次の項目は詳細設定のみで、軌跡の種類がキーフレームまたはカスタム軌跡の場合に表示されます。

| 項目 | 調整する内容 |
| --- | --- |
| 軌跡平滑化 | 軌跡の角を滑らかにします。0%では元の形を維持します。 |
| 微小揺れ | 軌跡へ小さな揺れを加えます。 |
| 柔らかさ | ブラシの中心から外周へ向かって拭き取りを弱めます。 |
| 拭き残し | 拭いた後に残る曇りを調整します。 |
| 拭きムラ | 拭き跡の不均一さを調整します。 |
| Seed | 微小揺れ、拭きムラ、曇りノイズのパターンを変えます。水滴のSeedとは別の設定です。 |
| 拭き取り強度 | ブラシによる拭き取りの強さを調整します。 |

### ハートなどの軌跡を使う

内蔵の「ハート」「相合い傘」「スマイル」は、軌跡のプリセットです。
適用後も制御点を編集できます。

1. 「設定方法」を「詳細設定」にします。
2. プリセットの「種類」を「軌跡」にします。
3. 内蔵の図柄を選び、「適用」を押します。
4. 確認画面で「はい」を選びます。
5. 展開されたカスタム軌跡を調整します。

現在のブラシ設定は保持されます。
ゼロから軌跡を作る場合は、種類を「軌跡」にして「空から作成」を押します。
残したい軌跡がある場合は、先にユーザープリセットへ登録してください。

### カスタム軌跡の制御点を編集する

1. 「軌跡の種類」を「カスタム軌跡」にし、内蔵プリセットまたは「空から作成」で編集する軌跡を用意します。
2. 一続きの軌跡を増やす場合は「ストロークを追加」、同じ軌跡の点を増やす場合は「制御点を追加」を押します。
3. 各制御点の「時刻%」「X px」「Y px」「接触%」を入力し、別の欄へフォーカスを移して確定します。
4. 「上へ」「下へ」で並びを変え、「削除」で不要なストロークや制御点を取り除きます。

「時刻%」は描画開始を0%、描画完了を100%とする位置です。
「接触%」を0%にした区間は拭きません。
最大64ストローク、各ストローク512点まで編集できます。

<a id="user-brush"></a>

## PNG画像をブラシにする

1. 「ブラシ」の形状を「ユーザー画像」にします。
2. 「登録名」に、一覧に表示する名前（例：テスト用ブラシ）を入力します。PNGのファイル名やパスを入力する欄ではありません。空欄のままではファイル選択画面を開けません。
3. 「PNGを追加」を押し、ファイル選択画面でフォルダーを開いてPNGを選び、「開く」を押します。同名の登録がある場合は、先に置換の確認画面が出ます。
4. 登録した画像が、そのエフェクトへ適用されます。登録済みの別の画像を使うときは、一覧から選んで「使用」を押します。

| 条件 | 登録できる範囲 |
| --- | --- |
| 形式 | アルファチャンネルを持つPNG |
| 大きさ | 幅と高さがそれぞれ1920px以下 |
| ファイルサイズ | 8MiB以下 |
| 登録数 | 最大100件 |

PNGの透過情報を拭き取り形状として使います。
全画素が不透明でもアルファチャンネルがあれば登録できますが、その場合は画像全体の四角い範囲がブラシになります。
透明な余白を切り取らず、登録したPNGの元キャンバス全体を寸法として使います。
SVGと、アルファチャンネルのないPNGは登録できません。
「手形」と「靴跡」は内蔵ブラシの名前なので、登録名には使えません。

画像はプラグインの管理フォルダーへコピーされます。
登録後に元のPNGを移動しても使えます。
「置換」は登録した項目を保ちながら画像を更新し、「削除」は確認後に登録情報と管理画像を削除します。
画像の見かけの大きさだけを変える場合は、「サイズ倍率」を調整します。
PNG自体の絵柄やキャンバス寸法を変える場合は「置換」を使います。
操作中のエフェクトには置換した画像が適用されます。
同じ画像を使う別のエフェクトでは、一覧から画像を選び「使用」を押して参照を更新してください。
その画像を使うプリセットも、参照を更新した設定で再登録します。

登録画像が欠落または破損した場合や、画像の置換後にエフェクト側の参照が古い場合は、入力映像をそのまま表示します。
一覧に項目が残っている場合は、その項目を「置換」して画像を復旧できます。
一覧から作り直した場合は、使うエフェクトでも新しいブラシを選び直してください。

<a id="presets"></a>

## よく使う設定をプリセットに保存する

ユーザープリセットは「軌跡」「ブラシ」「全設定」の3種類です。

| 種類 | 保存する内容 | 適用後も保つ内容 |
| --- | --- | --- |
| 軌跡 | カスタム軌跡、軌跡平滑化、微小揺れ、そのSeed | 現在のブラシと水滴設定 |
| ブラシ | 形状、生成形状の直径・幅・高さ、サイズ倍率、ユーザー画像の選択、左右反転、連続拭き、回転、拭き取りの強さ、回転追従、柔らかさ、拭き残し、拭きムラ、描画品質 | 現在の軌跡、軌跡の種類、軌跡平滑化、微小揺れ、そのSeed、水滴設定 |
| 全設定 | 上の軌跡とブラシに加え、水滴設定 | 曇り、領域、描画時間など、プリセットに含まれない設定 |

「全設定」にも、曇り量、ぼかし量、曇り色、領域、描画開始と完了は含まれません。
エフェクト全体の状態を残す場合は、YMM4のプロジェクトとして保存します。

### 登録する

定型軌跡でもプリセット欄は表示され、ブラシの登録と適用に使えます。
定型軌跡のままでは「軌跡」と「全設定」は登録できません。
「軌跡」または「全設定」を適用すると、軌跡の種類は「カスタム軌跡」に切り替わります。
同じ注意はプリセット欄のツールチップでも確認できます。

1. 「設定方法」を「詳細設定」にし、プリセットの「種類」を選びます。
2. 「軌跡」または「全設定」では、軌跡の種類を「カスタム軌跡」にして内容を整えます。「ブラシ」は、どの軌跡の種類でも登録できます。
3. 名前を入力します。名前は1文字から64文字です。
4. 「現在の設定を登録」を押します。
5. 同じ種類に同じ名前がある場合は、確認して上書きします。

3種類の合計で最大100件保存できます。
登録後は「ユーザー: 名前」と表示されます。
適用時には、その種類に含まれる値だけを変更します。
保存ファイルが破損している場合は、元ファイルを自動上書きせず、エラーを表示します。

<a id="save"></a>

## 保存、バックアップ、別のPCへの移行

### プロジェクトと登録データの違い

| 保存するもの | 保存先 |
| --- | --- |
| アイテムのエフェクト設定 | YMM4のプロジェクト |
| ユーザープリセットの一覧 | YMM4の設定フォルダー内の`YMM4GlassWipe\presets.json` |
| ユーザーブラシの一覧と画像 | YMM4の設定フォルダー内の`YMM4GlassWipe\brushes` |

ユーザーブラシのPNGは、YMM4のプロジェクトには埋め込まれません。
プロジェクトだけを別のPCへ移しても、登録画像は移りません。

### ユーザーブラシも移す場合

**同じ名前で登録し直すだけでは、元のプロジェクトの参照は復旧しません。**
名前とは別の識別情報でブラシを参照しているためです。

既存の参照を保って移す場合は、両方のPCでYMM4を終了し、`YMM4GlassWipe\brushes`フォルダー全体をバックアップして移します。
`brushes.json`と、その中の`images`フォルダーを一緒に保持してください。
移行先に既存の登録がある場合は先に退避し、一覧ファイルを安易に上書きしないでください。

フォルダーを移せない場合や、移行先の登録と共存させたい場合は、PNGを移行先で登録し、各エフェクトで新しいブラシを選び直します。
その画像を使うプリセットも、選び直した設定で再登録します。
ユーザープリセットの一覧を移す場合は、`presets.json`も別途バックアップします。

<a id="quality"></a>

## 描画品質と表示の確認

「描画品質」は、軌跡をつなぐブラシの配置密度を調整します。
手形・靴跡・ユーザー画像の連続拭きがONの場合は、移動、回転、大きさの変化を補間する細かさも変わります。

| 選択肢 | 動作 |
| --- | --- |
| 軽量 | ブラシの間隔を広げ、負荷を抑えます。 |
| 標準 | 標準の間隔で描画します。 |
| 高品質 | ブラシを密に配置します。 |
| 自動 | 定型軌跡で使用可能。一回拭きでは標準、往復では高品質を使います。 |

定型軌跡用の描画品質と、キーフレームやカスタム軌跡用の描画品質は別に保持します。
大きなブラシや強い拭き取りでは、品質を変えても見た目の差が小さいことがあります。
動作が重い場合は、描画品質や水滴量、水筋の長さを下げてプレビューを比較します。

<a id="debug-view"></a>

## デバッグ表示を使う

詳細設定の「デバッグ」にある「表示」は、領域や拭き跡が意図した状態になっているかを確認するための機能です。

| 表示 | 確認できること |
| --- | --- |
| 最終結果 | 曇り、拭き取り、水滴を合成した通常の映像を表示します。 |
| 領域マスク | 曇りを適用する範囲を、領域内は白、領域外は黒、境界は灰色で表示します。 |
| 拭き取りマスク | 現在までの拭き取り量を、強く拭いた場所は白、拭いていない場所は黒、中間は灰色で表示します。 |
| ぼかし | ぼかしを適用した後のカラー映像を表示します。 |
| 領域ローカルUV | 領域内の横位置と縦位置を色で表示し、領域の位置、回転、変形を確認できます。 |
| 四角形（四隅指定）の妥当性 | 四角形が有効な場合は緑、不正な場合は赤で表示します。 |

通常の映像へ戻すには、表示を「最終結果」にします。

<a id="trouble"></a>

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| エフェクト名が見つからない | YMM4を再起動し、「描画」を確認します。 |
| 曇りが見えない | 曇り量、領域、デバッグ表示を確認します。すでに拭き終わった再生位置なら先頭へ戻します。 |
| 拭き取りが始まらない | 選択中の時間指定方式と開始値、再生位置、進行度を確認します。往復では拭き取り量、キーフレームでは接触率も確認します。 |
| 一瞬で拭き終わる | 描画完了が開始以下になっていないかを確認します。パーセンテージではアイテムの長さも確認します。 |
| 手形・靴跡・ユーザー画像がスタンプのように残る | 「連続拭き」がOFFになっていないか確認します。別の形状から手形、靴跡またはユーザー画像へ変更するとONになります。同じ形状の再指定ではOFFを維持します。 |
| 円弧にならない | 経由点を使う拭き方と「円弧（3点）」を選び、3点を一直線や同じ位置に置かないようにします。 |
| 往復しても曇りが減らない | 拭き取り量を確認します。0%では拭き取らず、100%では最初に通った時点で拭き取ります。 |
| ずれが効かない | 拭き方を「往復拭き（ずれ）」にします。 |
| 水滴が見えない | 外側の水滴量と水滴の濃さを確認します。雨の降り始めがONなら、出現開始時間と出現期間を足した時間より後まで再生します。曇りが強すぎる場合も見えにくくなります。 |
| 水滴が垂れない | 水滴を垂らすをONにし、垂れる割合が0%でないことを確認します。出現直後には待機時間があるため、再生を続けて確認します。 |
| 拭いても水滴が残る | 外側の水滴は拭き取りの対象外です。水滴自体を表示しない場合は、外側の水滴量を0%にします。 |
| 輪郭の濃さや水滴の出現時間が表示されない | 輪郭の濃さは黒い輪郭かリアルのとき、水滴の出現時間は雨の降り始めがONのときに表示します。水滴量0%では両方とも非表示です。 |
| 「面に合わせる」が表示されない | リアルと簡易物理は領域内へ切り抜けますが、水滴の面変形には対応しません。動きを周期動作、見た目を白い輪郭／黒い輪郭にすると再表示します。 |
| 簡易物理で雨を増やしても滴が増えない | 同時256滴が上限です。合体や流出でも数が減ります。補給量は表示数の保証ではありません。 |
| 簡易物理の小さい滴が落ちない | 滑り始める大きさに達していない場合があります。水滴サイズや滑りやすさを上げるか、接触合体を使います。 |
| ブラシの寸法項目が見えない | 直径は円、幅・高さは楕円または四角形で表示します。手形、靴跡、ユーザー画像では「サイズ倍率」を表示します。連続拭きもこの3形状で表示します。 |
| ユーザー画像を使うと効果が消える | ブラシ一覧のエラーを確認します。画像の置換後は一覧から選んで「使用」を押します。欠落または破損した場合は、置換または登録し直して再選択します。 |
| 現在の設定を登録できない | 軌跡または全設定の登録では、正しいカスタム軌跡が必要です。ブラシだけを保存する場合は種類をブラシにします。 |
| プリセットの全設定を適用しても曇りが変わらない | 全設定プリセットにも曇り、領域、描画時間は含まれません。 |
| 四隅指定で効果が消える | 四辺が交差していないか、頂点が重なっていないかを確認します。 |
| 白黒の画像になる | 詳細設定のデバッグ表示を「最終結果」にします。 |

### 対応していない機能

現在、次の機能には対応していません。

- 水滴の物理的な背景屈折、分裂、曲面ガラスの物理変形、自動追跡
- 外側の水滴をブラシで拭き取る機能
- 空間を降る雨そのものの描画（降雨）
- EXO出力への本エフェクトの変換
- ユーザーブラシ画像のプロジェクトへの埋め込み

現在の「雨の降り始め」は、ガラス面の水滴が時間差で現れる機能です。
空間を降る雨を描く機能ではありません。
